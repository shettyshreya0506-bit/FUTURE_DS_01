# FUTURE_DS_01 – Business Sales Performance Analytics

## Project Overview

This project focuses on analysing business sales data using Microsoft Power BI. The objective is to understand sales performance, identify top-selling products, analyse regional and category-wise sales, and evaluate business profitability.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Business Data Analytics

## Dashboard KPIs

| KPI            | Value   |
| -------------- | ------- |
| Total Sales    | 2.30M   |
| Total Profit   | 286.40K |
| Total Orders   | 5K      |
| Total Quantity | 38K     |

## Analysis Performed

### 1. Top 10 Products

The Canon imageCLASS 2200 Advanced Copier is the highest-selling product, generating 61,599.82 in sales.

### 2. Monthly Sales Trend

- Highest sales month: November – 352,461.07
- Lowest sales month: February – 59,751.25
- September also recorded strong sales.

### 3. Regional Sales Performance

| Region  | Sales      |
| ------- | ---------- |
| West    | 725,457.82 |
| East    | 678,781.24 |
| Central | 501,239.89 |
| South   | 391,721.91 |

West is the highest-performing region, while South has the lowest sales.

### 4. Category Performance

| Category        | Sales      |
| --------------- | ---------- |
| Technology      | 836,154.03 |
| Furniture       | 741,999.80 |
| Office Supplies | 719,047.03 |

Technology is the highest-performing sales category.

### 5. Profitability Analysis

| Category        | Profit     |
| --------------- | ---------- |
| Technology      | 145,454.95 |
| Office Supplies | 122,490.80 |
| Furniture       | 18,451.27  |

Technology generates the highest profit, while Furniture has the lowest profit.

## Key Business Insights

- Technology leads in both sales and profit.
- West generates the highest regional sales.
- November records the highest monthly sales.
- Canon imageCLASS 2200 is the top-selling product.
- Furniture requires attention to improve profitability.

## Business Recommendations

- Maintain inventory of high-selling products.
- Improve marketing in low-performing regions.
- Introduce promotional offers during low-sales months.
- Review Furniture pricing and discount strategies.
- Monitor sales and profit regularly.

## Conclusion

This project demonstrates how Power BI can be used to analyse business sales data and generate meaningful insights. The dashboard helps identify sales trends, product performance, regional opportunities and profitability, supporting better business decisions.
